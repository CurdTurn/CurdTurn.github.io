Privacy policy

Claude Gmail is a private tool used by its owner, only on the owner's own Google accounts. Nobody else is meant to use it, and no other person's data is collected.

What it accesses

With the owner's consent, it uses the Gmail API to search and read messages and to download attachments. Some of the owner's accounts also allow it to change labels, write drafts and send mail.

Where the data goes

  • Sign-in tokens stay on the owner's computer. No server belongs to this tool.
  • Downloaded attachments are saved on the owner's computer.
  • Mail content the owner asks about can be passed to the AI assistant the owner runs, and so to that assistant's provider, under the owner's own account with that provider.
  • Data is not sold, used for advertising, or shared with anyone else.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
